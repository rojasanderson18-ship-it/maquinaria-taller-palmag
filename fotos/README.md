# Fotos de la maquinaria

El Taller muestra aquí la foto de cada máquina. El nombre del archivo es el
código de la máquina sin el `#`, en `.jpg`:

| Máquina | Archivo |
|---|---|
| #01 … #11 | `01.jpg` … `11.jpg` |
| Ford 5000 | `FORD.jpg` |
| VW Constellation | `EXX568.jpg` |
| Isuzu FVR | `SXY206.jpg` |

Mientras una foto no exista, se ve el dibujo del tractor o del camión.
Fotos horizontales, de unos 800 px de ancho, para que carguen rápido.
